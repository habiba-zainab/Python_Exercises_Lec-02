## 🎓 About
A personal Python learning repository documenting my progress through **Lecture 02: Strings & Conditional Statements**. This collection includes structured exercises, string manipulation practice, and an interactive email validator project.

---

## 📚 Overview
This repository contains my practice work for Lecture 02, focusing on string operations, text manipulation, and implementing conditional logic in Python programs.

---

## 📖 Topics Covered

### ✅ String Basics
* String creation and declaration
* Concatenation
* Escape sequences
* Multi-line strings
* String immutability

### ✅ Indexing & Slicing
* Positive indexing
* Negative indexing
* Slicing syntax `[start:stop:step]`
* Negative Slicing
* String reversal

### ✅ String Functions & Methods
* **Case conversion:** `upper()`, `lower()`, `title()`, `capitalize()`
* **Search and replace:** `find()`, `index()`, `replace()`, `count()`
* **Validation methods:** `is_alpha()`, `isdigit()`, `isalnum()`
* **Formatting:** `strip()`, `split()`, `join()`
* **Checking:** `startswith()`, `endswith()`

### ✅ Conditional Statements
* `if` statement
* `if-else` statement
* `if-elif-else` ladder
* Nested conditionals
* Logical operators with conditions
